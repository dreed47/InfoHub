This project is a fork of [PrintSphere](https://github.com/cptkirki/PrintSphere) by cptkirki. InfoHub extends that base with its own ideas and design decisions — the generic multi-plugin platform (weather, stocks, and Kconfig-toggleable plugin architecture), Web Config portal, and the additional features and refactors documented throughout this repository are original work on top of the fork. AI-assisted tools were used only selectively for implementation support and debugging.
